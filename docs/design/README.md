# Design Documents

Use this directory for detailed module/subsystem designs that describe **how the current or approved system should work**.

Recommended contents:
- purpose and scope;
- interfaces;
- data/control flow;
- state machines or algorithms;
- invariants and corner cases;
- error/backpressure behavior;
- verification strategy;
- performance/resource considerations.

Do not duplicate decision rationale that belongs in `docs/decisions/`.
